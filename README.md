## 📚 Spring Boot Documentation

This repository now includes comprehensive documentation on **Many-to-Many Relationship Setup in Spring Boot**:

### 🎯 Available Resources

1. **Interactive Slideshow** - View the slideshow presentation for a visual, step-by-step guide
   - Located in: `_posts/0000-01-02-many-to-many-spring-boot.md`
   - Covers all aspects with code examples and diagrams

2. **Quick Reference Guide** - [MANY_TO_MANY_GUIDE.md](MANY_TO_MANY_GUIDE.md)
   - Comprehensive markdown documentation
   - Easy to search and reference
   - Includes complete code examples for entities, repositories, services, and controllers
   - Best practices and common pitfalls
   - Testing examples and API usage

### 📖 Topics Covered

- **Database Design** - Understanding join tables and foreign keys
- **Entity Setup** - JPA annotations (@ManyToMany, @JoinTable, mappedBy)
- **Repository Layer** - Custom queries with JOIN FETCH
- **Service Layer** - Business logic and transaction management
- **Controller Layer** - RESTful API endpoints
- **Configuration** - H2 (development) and PostgreSQL (production)
- **JSON Serialization** - Handling circular references
- **Best Practices** - Performance optimization and data integrity
- **Testing** - Unit and integration tests
- **Advanced Patterns** - Intermediate entities with extra columns

### 🚀 Getting Started

To view the slideshow locally:
1. Install Jekyll: `gem install bundler jekyll`
2. Install dependencies: `bundle install`
3. Run the server: `bundle exec jekyll serve`
4. Open your browser to: `http://localhost:4000`

To read the guide, simply open [MANY_TO_MANY_GUIDE.md](MANY_TO_MANY_GUIDE.md) in your favorite markdown viewer or right here on GitHub!
